# Internationalization

The app ships in English and Brazilian Portuguese and must be fully localized. A key
missing from `intl_pt.arb` does not break the build — gen-l10n silently falls back
to English — so `test/l10n/arb_parity_test.dart` guards parity.

## Add a string

1. Add the key + English value + `@key` metadata to `lib/l10n/intl_en.arb`
   (the template).
2. Add the same key with the Portuguese value to `lib/l10n/intl_pt.arb`.
3. The post-edit hook runs `fvm flutter gen-l10n`; commit the regenerated
   `lib/l10n/app_localizations*.dart`.
4. In the widget: `final l10n = AppLocalizations.of(context)!;` then `l10n.myKey`
   (`import 'package:opfan/l10n/app_localizations.dart';`).

## Keys

- lowerCamelCase, prefixed by feature for anything not generic:
  `crewDeletionError`, `vegapunkRetry`, `namiBudgetTitle`.
- Reuse existing generic keys before adding new ones (`loadingError`, `error`,
  `errorLoadingContent`, `errorPrefix`). Search both ARBs first.
- Always add `"@key": {"description": "..."}` — it is the only context a translator
  has.

## Placeholders, plurals, numbers

```json
"crewMembersCount": "{count, plural, =0{No members} =1{1 member} other{{count} members}}",
"@crewMembersCount": {
  "description": "Member counter on the crew card",
  "placeholders": { "count": { "type": "num", "example": "3" } }
}
```

- Never concatenate translated fragments (`l10n.hello + name`); use a placeholder.
- Dates and numbers: `DateFormat`/`NumberFormat` with
  `Localizations.localeOf(context).toString()`. Currency is BRL via the feature
  formatter (`formatBrl`), not string building.

## Localizing failures

States hold a failure enum (see `bloc.md`); the widget maps it:

```dart
String _message(AppLocalizations l10n, CrewsFailure f) => switch (f) {
  CrewsFailure.network => l10n.errorNetwork,
  CrewsFailure.notFound => l10n.crewNotFound,
  CrewsFailure.permissionDenied => l10n.permissionDenied,
  CrewsFailure.unknown => l10n.errorLoadingCrews,
};
```

## Locale

- UI reads and switches the locale only through `LocaleCubit`
  (`context.read<LocaleCubit>().setLocale(const Locale('pt'))`).
- Non-UI code (AI prompts) injects `ILocaleService` and calls
  `PromptLocale.isPortuguese(localeService)`; `languageCode` already falls back to
  the device language. Only `locale_service.dart` may read the device locale.
- Never read `Platform.localeName` or `PlatformDispatcher.instance.locale`.

## What is not localized

Proper nouns from One Piece (character names, `haki`, `yonkou`) may be identical in
both files. Domain keys stored in data (crew role keys, haki keys, affiliation
keys) are stable English identifiers mapped to text by
`lib/core/utils/character_localization_mapper.dart` — never store translated text
in Firestore or Hive.
